# Gestor de cuentas bancarias
Este repositorio contiene una aplicación creada con la finalidad de poder gestionar varias cuentas bancarias en un mismo lugar.

Se encuentra en desarrollo, por lo que de momento permite la autenticación de usuarios, añadir cuentas bancarias y movimientos, y consultar tanto el saldo total de cada cuenta como el historial de movimientos. También se muestra el dinero total que se posee entre todas las cuentas.

*En la versión actual cuya finalidad era poder abrir la aplicación a su uso en redes externas, ha corrompido la autenticación, por lo que no permite ejecutar los servicios posteriores a la autenticación del usuario.
